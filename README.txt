HirePilot AI V2 Prototype

Included:
- Expected/current CTC, hike and salary source
- Total + relevant experience
- Industry/domain, skills, location
- Notice period and recruiter notes
- Bulk CV selection
- Strict duplicate blocking by email, phone, or name+company
- Manual candidate profile entry
- Candidate search prototype
- Local browser storage

Important: TXT files are parsed in this offline prototype. PDF/DOCX files are detected but require a production parser/backend. Future production version should add real AI extraction, semantic search, secure database, authentication, backups and audit logs.

Open index.html in Chrome or Edge.
